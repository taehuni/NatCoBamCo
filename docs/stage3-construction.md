# 3단계 첫 작업: 건설 카드와 비용 연결

확인일: 2026-09-12. 브랜치 `feature/Min`, 기준 커밋 `b31df90`.

## 문제와 수정 범위

Main의 BuildQuickUI에 카드 9개가 있었지만 모든 buildPrefab과 buildingSystemObject 참조가 비어 있었다. UI가 SendMessage로 호출하는 StartPlacement는 BuildingSystem에 없었다. B키의 기존 건설은 비용 없이 Instantiate만 호출했다.

- 신규 `BuildCost.cs`: 네 자원의 실제 비용과 표시 문자열을 같은 데이터에서 제공한다. configured가 false인 미설정 비용과 음수 비용을 거절한다.
- `BuildItem.cs`: cost 필드 하나를 추가한다. 기존 이름·설명·아이콘·프리팹 필드는 유지한다.
- `BuildCardUI.cs`: 실제 비용을 표시하고 프리팹 없는 카드는 `준비 중` 및 비활성 버튼으로 남긴다.
- `BuildQuickUI.cs`: 실제 BuildingSystem.StartPlacement를 호출한다. 메뉴를 열 때 미리보기를 정리하고 조작을 멈추며, 닫을 때 각 스크립트의 열기 전 enabled 상태를 복원한다.
- `BuildingSystem.cs`: 카드와 기존 B/1/2/3 경로가 동일한 비용 데이터를 사용한다. 바닥·회전·겹침·잔액을 배치 직전에 다시 검사하고, 비활성 상태로 생성한 뒤 비용 차감에 성공하면 실제 건물을 활성화한다. 같은 프레임의 중복 생성도 차단한다. 메뉴 선택 클릭이 곧바로 건설 입력으로 이어지지 않게 한다.
- 미리보기 복제본은 기존 렌더러와 재질 표시·회전을 유지한다. 복제본의 게임 스크립트·콜라이더·NavMeshObstacle을 비활성화하고 피격 컴포넌트를 제거한다. 실제 프리팹과 건물 공격/피격 스크립트는 수정하지 않았다.
- Main 씬: 기존 카드 5개에 프리팹을 연결하고 카드 9개에 기존 표시 비용을 숫자로 옮겼다. 메뉴 제어 대상은 PlayerController, PlayerShoot, CameraFollow, BuildingSystem이다. 씬 이동 시 임시 미리보기와 건설/철거 모드가 정리된다.

BuildItem, BuildCardUI, BuildQuickUI의 기존 CP949 인코딩은 유지했다. 씬은 Unity Editor API로 편집했다. 사용자 폰트 변경은 별도로 보존한다.

## 현재 비용

기존 카드의 수치를 그대로 사용했으며 최종 밸런스 확정은 아니다. `철`은 `금속`, `부품`은 사용자 확정 명칭인 `희귀 금속`으로 표시한다.

| 카드 | 프리팹 | 목재 | 금속 | 희귀 금속 |
|---|---|---:|---:|---:|
| 나무 벽 | Wall | 20 | 0 | 0 |
| 기관총 타워 | Tower | 0 | 60 | 35 |
| 저격 타워 | SniperTower | 0 | 80 | 45 |
| 전기 타워 | ElectricTower | 0 | 65 | 40 |
| 의료소 | MedicalCenter | 40 | 0 | 30 |
| 철제 벽 | 준비 중 | 15 | 40 | 0 |
| 강화 벽 | 준비 중 | 0 | 70 | 30 |
| 연구소 | 준비 중 | 0 | 80 | 50 |
| 정비소 | 준비 중 | 0 | 60 | 45 |

식량 비용은 현재 모두 0이다. 프리팹 없는 카드에 다른 건물을 대신 연결하지 않았다.

## 검증 결과

실제 Unity Main 씬의 바닥, 기존 프리팹 5개, 원래 건설 메뉴·카드·자원 HUD로 Play 검사 78개가 통과했다. 검사 구간 Error/Exception은 0개였다.

- 카드 개수·프리팹 연결·표시/실제 비용 일치 및 미설정 비용 거절.
- 카드 버튼에서 미리보기 진입, 준비 중 카드 비활성화, 메뉴 입력 정지와 이전 enabled 상태 복원.
- 자원 부족 시 건물 미생성·무차감, 취소 시 무차감.
- 다섯 건물 각각 미리보기 표시·회전, 복제본의 게임 기능/충돌/피격/내비게이션 비활성 상태.
- Main 바닥 배치, 비용 1회 정확한 차감, 연속 중복 호출과 겹침 배치 거절, 위치·회전 일치, 실제 건물의 원래 enabled 기능과 양수 체력 유지, 자원 HUD 갱신.
- 바닥 없는 방향에서 배치 거절. Main↔Collection 왕복 시 임시 미리보기 정리와 기존 메뉴·건설 시스템 유지, 귀환 후 카드에서 다시 배치 시작.
- 실제 Game View 캡처로 카드 비용과 초록색 전기 타워 미리보기 확인. 기존 카드 레이아웃과 가로 스크롤을 유지했다.

테스트는 버튼 이벤트와 건설 메서드를 코드로 호출했다. 물리 N/B/R/숫자키·마우스 입력, 전투 피해량 검증, 건물 상태의 씬 왕복 복원은 이번 통과 범위가 아니다. 기존 무기 설정 문제 해결을 뜻하지도 않는다.
